# THE NURSE SCRIBE

GitHub-ready React + TypeScript website generated from the LlamaCoder project.

## Run locally

1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Build

Run `npm run build`. The production files are generated in `dist/`.

## GitHub Pages

This project uses a relative Vite base (`./`), so it can be deployed from a GitHub Pages project repository without changing asset paths.
